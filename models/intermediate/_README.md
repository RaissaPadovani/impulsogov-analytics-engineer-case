# Intermediate

Nesta pasta entrarão os modelos que aplicam regras de negócio depois do profiling, por exemplo:

- deduplicação das transmissões;
- população elegível para hipertensão;
- última consulta válida;
- última aferição de pressão válida;
- último registro simultâneo de peso e altura.

Não preencher antes de registrar as decisões em `docs/decisoes.md`.
